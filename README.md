# LIVE SIMULATOR — 配信ごっこ

YouTubeのライブ配信ページを参考にした、非公式の配信シミュレーターです。
HTML/CSS/JavaScriptだけで動くので、GitHub Pagesなどの静的ホスティングにそのまま置けます。

## ファイル
- `index.html` — 画面本体
- `styles.css` — デザイン
- `script.js` — 配信シミュレーションの処理

## 今できること
- 配信タイトルを設定
- 配信者名を設定
- 登録者数を設定
- 開始時の視聴者数・高評価数を設定
- チャンネルアイコンをブラウザ内で設定
- 配信背景画像をブラウザ内で設定
- 配信開始／終了
- 経過時間表示
- 視聴者数の自動変化
- 高評価ボタン
- チャンネル登録ボタン
- 自動チャット
- 自分のコメント送信
- 配信者コメント送信
- 共有リンク生成（設定をURLに埋め込み）

## 注意
この版は「配信ごっこ」のシミュレーションです。
複数人が同じ配信に接続してコメントをリアルタイム共有する機能は、サーバーやデータベースが必要です。
また、YouTubeの公式サービスではありません。
